后台操作记录增加用户 ID 显示及搜索功能


1.记录用户 ID： 管理员在后台执行涉及用户的操作时，操作日志需记录对应的被操作用户 ID。


2.支持多个用户 ID： 当一次操作涉及多个用户时，需记录该次操作涉及的全部用户 ID。


3.显示用户 ID： 在后台操作记录列表中增加用户 ID 字段，用于展示该条操作记录关联的用户 ID。


4.支持用户 ID 搜索： 增加用户 ID 搜索条件，支持根据用户 ID 筛选操作记录。


5.搜索匹配规则： 如果一条操作记录关联了多个用户 ID，只要其中任意一个用户 ID 与搜索条件匹配，就需要返回并显示该条操作记录。
